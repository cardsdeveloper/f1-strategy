# Stratégie F1 — Dégradation pneumatique & simulateur d'arrêts aux stands

🚧 Projet en cours

Modélisation de l'usure des pneus (Soft/Medium/Hard) à partir de la télémétrie officielle F1 (FastF1),
et simulateur d'optimisation des arrêts aux stands (undercut / overcut, 1 vs 2 arrêts).

**Stack :** Python · FastF1 · pandas · NumPy · SciPy · scikit-learn · Matplotlib · Seaborn

## Étapes
- [ ] Extraction des données d'un Grand Prix
- [ ] Nettoyage (SC/VSC, in/out laps, trafic)
- [ ] Modèle de dégradation par composé
- [ ] Simulateur de stratégies et probabilité d'undercut
